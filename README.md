## Descripción
Trabajo práctico de la materia **Simulación**, cuyo objetivo es modelar y analizar el funcionamiento de un sistema de atención de trámites mediante simulación de eventos discretos.

## Metodología
- Procesamiento y análisis de datos históricos de arribos y tiempos de atención.
- Ajuste de distribuciones de probabilidad para modelar las variables aleatorias del sistema.
- Generación de muestras a partir de las distribuciones seleccionadas.
- Implementación de un simulador con colas FIFO, puestos de atención exclusivos y evaluadores compartidos.
- Ejecución de distintos escenarios para analizar el comportamiento del sistema.

## Tecnologías utilizadas
- Python
- Pandas y NumPy
- SciPy
- Matplotlib
- Google Colab

## Métricas analizadas
- Tiempo promedio de permanencia de los trámites.
- Porcentaje de trámites derivados a puestos compartidos.
- Porcentaje de ociosidad de los puestos exclusivos.

## Ejecución
El proyecto se desarrolla en un notebook de Google Colab. Para ejecutarlo, es necesario disponer de los datasets utilizados y actualizar las rutas de acceso correspondientes.
